# 奥术大师 (Arcane Master) ✨

一个基于Web的魔法主题回合制战斗游戏，采用现代化的UI设计和流畅的动画效果。

![游戏预览](https://img.shields.io/badge/Status-Ready%20to%20Play-success)
![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## 🎮 游戏简介

在《奥术大师》中，你将扮演一位强大的魔法师，通过施放各种奥术法术与邪恶的敌人战斗。击败敌人获取经验值，提升等级，成为真正的奥术大师！

## ✨ 游戏特性

- 🔮 **多种法术系统** - 6种不同的魔法法术，各具特色
- ⚔️ **回合制战斗** - 策略性的战斗机制
- 📈 **等级系统** - 击败敌人获得经验值并升级
- 👹 **多样化敌人** - 5种不同类型的敌人，各有不同的能力
- 💫 **精美动画** - 流畅的战斗动画和法术效果
- 🎨 **现代化UI** - 采用渐变色和毛玻璃效果的美观界面
- 📱 **响应式设计** - 支持桌面和移动设备

## 🚀 快速开始

### 在线游玩

1. 克隆仓库：
```bash
git clone <repository-url>
cd workspace
```

2. 直接在浏览器中打开 `index.html` 文件即可开始游玩！

### 本地服务器运行（推荐）

如果你想使用本地服务器运行游戏，可以使用以下方法之一：

**使用Python：**
```bash
# Python 3
python -m http.server 8000

# 然后在浏览器中访问 http://localhost:8000
```

**使用Node.js：**
```bash
# 安装http-server
npm install -g http-server

# 启动服务器
http-server

# 然后在浏览器中访问显示的地址
```

**使用VS Code Live Server：**
- 安装 Live Server 扩展
- 右键点击 `index.html` 文件
- 选择 "Open with Live Server"

## 🎯 游戏玩法

### 基本操作

1. **开始战斗** - 点击"开始战斗"按钮召唤一个随机敌人
2. **施放法术** - 在战斗中点击法术卡牌来攻击敌人
3. **治疗** - 使用30点法力值恢复40点生命值
4. **冥想** - 跳过回合并恢复50点法力值
5. **重置游戏** - 重新开始游戏

### 法术系统

| 法术 | 图标 | 法力消耗 | 伤害 | 描述 |
|------|------|----------|------|------|
| 火球术 | 🔥 | 20 | 25 | 投掷一颗炽热的火球 |
| 冰锥术 | ❄️ | 15 | 20 | 召唤锋利的冰锥攻击敌人 |
| 闪电链 | ⚡ | 30 | 35 | 释放强大的闪电能量 |
| 奥术飞弹 | 🌟 | 25 | 30 | 发射追踪的奥术能量 |
| 暗影箭 | 🌑 | 18 | 22 | 射出穿透的暗影之箭 |
| 神圣之光 | ✨ | 35 | 40 | 召唤圣光净化邪恶 |

### 敌人类型

- 👹 **暗影恶魔** - 生命值: 80 | 攻击力: 15 | 经验: 30
- 🔥👿 **火焰巨魔** - 生命值: 100 | 攻击力: 20 | 经验: 40
- 🐉 **冰霜巨龙** - 生命值: 150 | 攻击力: 25 | 经验: 60
- 🧙‍♀️ **黑暗法师** - 生命值: 90 | 攻击力: 18 | 经验: 35
- 💀 **骷髅王** - 生命值: 120 | 攻击力: 22 | 经验: 50

### 升级系统

- 击败敌人获得经验值
- 达到所需经验值后自动升级
- 每次升级获得：
  - 生命值上限 +20
  - 法力值上限 +30
  - 完全恢复生命值和法力值

## 💡 游戏策略

1. **法力管理** - 合理使用法力值，在关键时刻使用强力法术
2. **生命值监控** - 当生命值较低时及时使用治疗术
3. **法术选择** - 根据敌人的血量选择合适的法术
4. **资源平衡** - 在攻击和恢复之间找到平衡
5. **升级优先** - 尽量击败更多敌人来提升等级

## 🔧 自定义和扩展

游戏代码结构清晰，易于扩展：

### 添加新法术

在 `game.js` 中的 `spells` 数组添加新的法术对象：

```javascript
{
    id: 7,
    name: "陨石术",
    icon: "☄️",
    manaCost: 50,
    damage: 60,
    description: "召唤天降陨石"
}
```

### 添加新敌人

在 `game.js` 中的 `enemyTypes` 数组添加新的敌人类型：

```javascript
{
    name: "远古泰坦",
    icon: "🗿",
    health: 200,
    damage: 30,
    exp: 80
}
```

### 调整游戏平衡

修改 `gameState.player` 中的初始属性值来调整游戏难度：

```javascript
player: {
    health: 150,      // 增加初始生命值
    maxHealth: 150,
    mana: 200,        // 增加初始法力值
    maxMana: 200,
    exp: 0,
    level: 1,
    expToNextLevel: 100
}
```
